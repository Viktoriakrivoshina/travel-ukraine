## 📖 Про проєкт

**Travel Ukraine** — це туристичний вебзастосунок, створений для популяризації історичної, культурної та архітектурної спадщини України.

Сайт надає можливість переглядати екскурсії, ознайомлюватися з туристичними маршрутами та отримувати інформацію про екскурсоводів.

## ✨ Основні можливості

- 🏛️ Перегляд екскурсій у різних містах України.
- 📸 Перегляд фотографій туристичних місць.
- 📝 Детальні описи екскурсій.
- 💰 Інформація про вартість та тривалість.
- 👩‍💼 Перегляд профілів екскурсоводів.
- ⭐ Перегляд рейтингів гідів.
- ✅ Інформація про доступність екскурсоводів.

## 🌍 Міста та екскурсії

### 🏙️ Київ

- Святині та історія Старого Києва.
- Таємниці київського метро та підземель.
- Велич Києво-Печерської Лаври.

### 🏰 Львів

- Легенди та містифікації старого Львова.
- Кавовий аромат та традиції міста.
- Архітектурні шедеври Австро-Угорщини.

### 🌊 Одеса

- Кримінальна Одеса: міф і реальність.
- Архітектура та шик Дерибасівської.
- Одеські катакомби: мережа та історія.

## 🚀 Встановлення та запуск

### 1. Клонування репозиторію

```bash
git clone <URL-ВАШОГО-РЕПОЗИТОРІЮ>
```

### 2. Перехід до папки проєкту

```bash
cd cross_platform_app
```

### 3. Встановлення залежностей

```bash
flutter pub get
```

### 4. Запуск застосунку

```bash
flutter run
```

Для запуску вебверсії у Google Chrome:

```bash
flutter run -d chrome
```
